# Security policy

## Supported versions

Only the latest release is supported with security fixes.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature on this repository. Do not open a public issue for a vulnerability that could put users at risk.

The plugin downloads Chromium only after user confirmation and verifies the archive against a checksum pinned in source. T3 URLs and browser content are controlled by the user; treat remote URLs with the same care as a normal browser.
