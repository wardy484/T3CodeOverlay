# Changelog

All notable changes are documented here. Versions follow semantic versioning using four numeric assembly components.

## 0.1.0 — 2026-09-19

- Add a draggable T3 Code bubble with working and attention badges.
- Add an attached, rounded browser window with smooth open and close animation.
- Add focus-aware opacity, configurable idle opacity, and animation settings.
- Add T3 server reachability feedback.
- Add Windows, Linux, and Wine-compatible T3 thread-state discovery.
- Isolate every renderer instance with unique IPC and shutdown handles.
- Add deterministic packaging, Windows CI, and release automation.
